# English Lab

Многопользовательская платформа изучения английского в Telegram для отдела АБП.
Курс грамматики A1–C2 по темам, тренажёр с интервальным повторением, адаптивная
диагностика уровня, аудирование, устная практика с расшифровкой, разбор письма и
произношение с озвучкой.

Ядро — Python 3.11+ и стандартная библиотека, без внешних пакетов. Отдельно ставится только локальная речь: `faster-whisper` и `piper-tts` в `.venv`.

## Что внутри

**Курс.** 221 правило и 1768 упражнений на шести уровнях. Структура повторяет
test-english.com: уровень → тема → правило. Каждое правило — объяснение
по-русски, схемы формы, примеры, отдельным пунктом ловушка для русскоязычного, и
восемь упражнений пяти типов.

**Диагностика.** Адаптивная лестница A1–C2: блок из четырёх заданий,
подъём при 75 % верных, спуск при 34 %, потолок 28 заданий. Задания берутся из
самого курса, поэтому диагностика растёт вместе с контентом.

**Тренировка и повторение.** Тренировка держит долю верных в коридоре 60–75 %,
подстраивая сложность на ходу. Каждый ответ обновляет карточку SM-2, повторение
поднимает то, у чего подошёл срок. Лексика спрашивается в обе стороны.

**Аудирование.** 30 заданий A1–C2 на основную мысль, детали, вывод, отношение и
последовательность. Бот озвучивает скрытый скрипт локальным Piper, даёт до трёх
прослушиваний и показывает текст только после ответа.

**Речь.** Кнопка «🎙 Речь» даёт задание по уровню. Голосовое расшифровывается Whisper,
измеряется темп и число заполнителей, разбор идёт по четырём измерениям. Про
звуки честно сказано, что это гипотеза по расшифровке, а не оценка звучания.

**Письмо.** Задание с объёмом и фокусом, оценка по четырём критериям
и переписанный вариант на полступени выше с сохранением голоса автора.

**Произношение.** `/say schedule` возвращает одно голосовое: в подписи слово,
транскрипция General American, слоги и заметка, внутри — озвучка с американским
акцентом. Есть кнопка «медленно, по слогам». Слова из банка отвечаются без ИИ.

**Общение.** Свободный чат и ролевой диалог — шесть готовых ситуаций кнопкой или
свой сценарий через `/roleplay <сценарий>`. Блок правок по категориям, максимум
пять за сообщение, с пометкой повторяющихся ошибок.

**Справочный ассистент.** `/help <вопрос>` отвечает, как пользоваться English
Lab. Перед обращением к модели локальный поиск выбирает релевантные статьи из
проверяемой базы знаний; ответ ограничен найденными фактами. `/help` без вопроса
мгновенно показывает краткую карту возможностей и не расходует ИИ.

**Команда.** Вход по одноразовым приглашениям, роли, таблица отдела с отключаемым
участием, выгрузка выученного файлом для импорта в Anki.

**Навигация.** Команды помнить не нужно: внизу экрана пять кнопок. Главная —
«🎯 Заниматься»: она сама решает, что сегодня полезнее — добить очередь
повторения, взять новую тему, поговорить или потренировать слух, — и сразу это запускает. От
нажатия до первого задания на экране не больше трёх сообщений.

Интерфейсы разделены: у действия ровно одна точка входа. Кнопки закрывают всё
ежедневное, командами остаётся то, чего кнопкой не сделать, — `/say`, `/learn`
и `/roleplay` с произвольным аргументом, `/help <вопрос>`, `/stop`, `/privacy`,
`/forget YES`, `/admin` и вход `/start`.

## Запуск

1. Создать `.env` из `.env.example`, заполнить `TELEGRAM_BOT_TOKEN` и `BOT_CLAIM_CODE`.
2. Проверки: `.venv/bin/python -m unittest discover -s tests -v` и `python3 -m english_bot.content.validate`.
3. Вручную: `set -a; source .env; set +a; .venv/bin/python -m english_bot`.

Постоянная работа через user-service:

```bash
mkdir -p ~/.config/systemd/user
ln -s /home/milton/english/deploy/english-tutor-bot.service ~/.config/systemd/user/english-tutor-bot.service
systemctl --user daemon-reload
systemctl --user enable --now english-tutor-bot.service
```

Первый, кто пришлёт `/start <BOT_CLAIM_CODE>`, становится владельцем. Дальше
владелец раздаёт коллегам ссылки кнопкой «📊 Я» → «Пригласить коллегу».

## Два переключателя

Курс, тренировка, повторение, диагностика, локальный поиск справки и `/help` без
вопроса работают без ключей и без сети. Генеративные функции питаются двумя
независимыми контурами, и каждый переключается одной строкой в `.env` — код при
этом не меняется.

**Текст: `LLM_PROVIDER`**

| Значение | Чем платим | Скорость |
|---|---|---|
| `codex` | ничем, идёт через подписку ChatGPT | 8–12 с на ответ |
| `openai` | токенами, нужен `OPENAI_API_KEY` | быстро |
| `anthropic` | токенами, нужен `ANTHROPIC_API_KEY` | быстро |

`codex` запускает `codex exec` подпроцессом в пустой временной папке под
песочницей `read-only`. Нужен установленный и залогиненный Codex CLI: проверить —
`codex login status`.

**Голос: `SPEECH_BACKEND`**

| Значение | Чем платим | Что нужно |
|---|---|---|
| `local` | ничем, работает офлайн | `.venv` с `faster-whisper` и `piper-tts` |
| `openai` | токенами | `OPENAI_API_KEY` |

У подписки Codex нет ни распознавания, ни синтеза — поэтому голос закрывается
локальными моделями. Расшифровка идёт на CPU примерно в 1.6 раза медленнее
записи: минутный ответ обрабатывается около 70 секунд, и бот об этом честно
предупреждает.

Переключение на API, когда наиграетесь с подпиской:

```bash
# в .env
LLM_PROVIDER=openai
SPEECH_BACKEND=openai
OPENAI_API_KEY=sk-...

systemctl --user restart english-tutor-bot.service
```

`DAILY_AI_CALLS` ограничивает число обращений на человека в сутки при любом
провайдере.

## Нагрузка

У каждого пользователя собственная последовательная очередь, но разные люди
обрабатываются общим пулом (`WORKERS=16`). Codex/API, Whisper и Piper вынесены в
отдельные пулы (`LLM_WORKERS=2`, `STT_WORKERS=1`, `TTS_WORKERS=1`), поэтому
минутная расшифровка не блокирует polling и чужие занятия. Исходящие сообщения
ограничены ниже лимитов Telegram, а ответ 429 повторяется после `retry_after`.

На машине проекта синтетическая проверка дала 741 запись SQLite/с при 16 потоках;
160 параллельных пользовательских задач использовали 15.4 из 16 workers. Пик с
Piper и Whisper — 914 МиБ при лимите сервиса 1600 МиБ. Полный аудит и границы:
[docs/operations.md](docs/operations.md#производительность-и-backpressure).

## Локальная речь: как поставить заново

```bash
python3 -m venv --without-pip .venv
curl -sSL https://bootstrap.pypa.io/get-pip.py | .venv/bin/python -
.venv/bin/python -m pip install faster-whisper piper-tts
.venv/bin/python -m piper.download_voices en_US-lessac-medium --download-dir data/models/piper
```

Модель распознавания скачивается сама при первом голосовом. Занимают: `.venv`
~490 МБ, whisper `small.en` ~464 МБ, голос piper ~61 МБ.
